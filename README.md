## 📖 Overview

A foundational machine learning repository covering core ML concepts, algorithms, and workflows. This project is designed as a learning resource that progresses from basic concepts to practical implementations on real datasets.

---

## 📚 Topics Covered
Q
### Core Concepts
- Supervised vs Unsupervised vs Reinforcement Learning
- Bias-Variance Tradeoff
- Overfitting and Underfitting
- Cross-Validation (K-Fold, Stratified)
- Feature Engineering and Selection

### Algorithms
- Linear & Logistic Regression
- Decision Trees and Random Forests
- Support Vector Machines
- K-Nearest Neighbors
- Naive Bayes
- K-Means Clustering

### Model Evaluation
- Confusion Matrix, Accuracy, Precision, Recall, F1
- ROC-AUC Curve
- Mean Squared Error, R² Score
- Learning Curves
